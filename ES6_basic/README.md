# ES6 Basics

## Description
This project covers the fundamental concepts of ES6 (ECMAScript 2015), focusing on modern JavaScript syntax and best practices.

## Learning Objectives
*   Variables (let and const)
*   Arrow functions
*   Rest and Spread parameters
*   Template literals
*   Iterables and For...of loops

## Requirements
*   NodeJS 20.x
*   Jest (Testing)
*   ESLint (Linting with Airbnb style)
