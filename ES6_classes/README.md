# ES6 Classes

## Description
An exploration of Object-Oriented Programming in JavaScript using ES6 Classes. This project demonstrates structured code through inheritance, encapsulation, and metaprogramming.

## Learning Objectives
*   Class declaration and instantiation
*   Methods, Static methods, and Getters/Setters
*   Class inheritance (Extends and Super)
*   Abstract-like class patterns
*   Metaprogramming with Symbols (`toStringTag`, `toPrimitive`, `species`)

## Requirements
*   NodeJS 20.x
*   Babel (Transpilation)
*   Jest & ESLint
